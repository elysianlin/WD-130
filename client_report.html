Client Report

I decided what content and images to use based on what would best represent my brand and clearly communicate with my audience. I chose clean, simple images that matched the tone of my site. Communication with my developer was smooth, although I sometimes needed to clarify what I wanted. My developer met my expectations and delivered a site that matched my vision. Next time, I will provide more detailed instructions from the beginning to avoid misunderstandings.

Link to the site: https://noahmackay.github.io/wdd130-lin/

Lead Developer Report

I managed my development team by dividing tasks into clear sections and communicating through group messages and GitHub issues. Communication with the client was good, and I asked follow-up questions when needed. I published the client’s site through GitHub Pages and shared the link for review. Managing the site with GitHub was helpful for version control, and although there were small learning challenges at first, the workflow became smooth.

Link to the site: https://elysianlin.github.io/Wdd130-Anderson/

Junior Developer Report

I communicated with my team lead through messages and GitHub comments, and there were no major communication issues. I clearly understood what was expected of me for each site and was able to contribute both code and styling. At first, I had minor issues with GitHub merge conflicts, but I resolved them by learning to pull updates before pushing.

General Experience and Reflections

The most challenging part of this project was managing multiple roles and keeping everything organized, but I overcame it by breaking tasks into smaller parts. I enjoyed seeing the sites come together and experiencing real teamwork. If I could redo the project, I would plan communication and file organization more carefully from the beginning. After this experience, I feel more confident working on real-world projects because I gained hands-on experience with client communication, collaboration, GitHub workflows, and publishing websites.
